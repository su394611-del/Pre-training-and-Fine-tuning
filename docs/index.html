LLM Fine-Tuning and Preference Optimization

Educational Python implementations of large language model fine-tuning using PyTorch, Hugging Face Transformers, PEFT and TRL.

Project Features

  • Qwen2.5-0.5B-Instruct fine-tuning
  • Low-Rank Adaptation (LoRA)
  • Supervised Fine-Tuning (SFT)
  • Direct Preference Optimization (DPO)
  • Odds Ratio Preference Optimization (ORPO)
  • Hugging Face Transformers and PEFT
  • Hugging Face TRL training workflows
  • JSONL dataset validation
  • Model tokenization and training
  • Adapter checkpoint generation
  • Python and Jupyter Notebook demos

Qwen LoRA Fine-Tuning

Fine-tune Qwen2.5-0.5B-Instruct using 49 educational instruction-answer examples and parameter-efficient LoRA adapters.

SFT, DPO and ORPO

Explore supervised fine-tuning followed by preference optimization using DPO, or a separate ORPO training experiment. These use small demonstration datasets.

Training Technologies

Python, PyTorch, Transformers, PEFT, TRL, LoRA and Hugging Face Datasets.
